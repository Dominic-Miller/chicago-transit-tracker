Privacy

Open Transit Chicago is designed to work without an account, advertising profile, or location history.

Location

Your browser asks for location only after you choose to enable it. Coordinates are kept in browser memory and sent to the Open Transit Chicago server only to find nearby stops and stations. They are not stored in a database.

Transit data

The server requests current predictions and vehicle positions from CTA and public geographic data from the City of Chicago. The application never places CTA API keys in the browser.

Storage and analytics

The installed web app stores its interface files so it can open reliably. Live predictions, vehicle positions, location responses, and map tiles are not saved for offline display. This pilot does not use product analytics, advertising trackers, cookies, or user accounts. Its hosting provider receives ordinary request metadata, such as IP address and browser type, in service logs; that information is not used to build rider profiles.
